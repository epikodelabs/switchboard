# Switchboard ASP.NET Core server template

This is a distributable `dotnet new` template for Switchboard protected frame delivery.
It consumes the `.switchboard/server` publication generated by
`@epikodelabs/switchboard-builder`, authorizes requested frame artifacts, and serves
only the exact content hash currently published for an authorized principal.

Pack and install locally:

```bash
dotnet pack pack/Switchboard.Templates.csproj -c Release -o ../../dist/templates
dotnet new install ../../dist/templates/EpikodeLabs.Switchboard.Templates.1.0.1.nupkg
dotnet new switchboard-server-aspnet -n MySwitchboardServer
```

Replace `DemoPrincipalStore` with your authentication integration before production.
